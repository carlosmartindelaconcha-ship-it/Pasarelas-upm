Prueba específica de mDNS

La API de Safari no expone si un nombre .local se resuelve ni su dirección resultante. Este ensayo compara dos negociaciones nuevas: una sin cambios y otra sustituyendo los candidatos UDP host .local remotos por una IPv4 conocida. No modifica el candidato original, ni los puertos ni los parámetros ICE.

En la prueba de hotspot, el participante puede comprobar la IP del iPhone anfitrión en Ajustes → Wi-Fi → ⓘ → Dirección IPv4 → Router. Solo en ese participante selecciona «Experimental» e introduce esa IP. En el maestro deja «Normal» si el candidato del participante ya contiene una IPv4. Selecciona el modo antes de pulsar «Crear oferta / preparar participante».
